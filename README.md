# YummyDownloader

Качалка аниме с YummyAnime без запуска плеера: забирает HLS-поток из Kodik и складывает `.mp4` по папкам. Форк [foxycuter2-ai/YummyDownloader](https://github.com/foxycuter2-ai/YummyDownloader) с GUI на tkinter.

## Запуск (Windows)

### Скачивание

Вариант 1 — зелёная кнопка Code → Download ZIP → распаковать. Вариант 2 — `git clone https://github.com/Freelancer14/YummyDownloader.git`.

Двойной клик по `Start_GUI.cmd` — сам проверит Python 3.9+ (при отсутствии вызовет `Setup_Python.cmd` и поставит зависимости), затем откроет окно: вставь ссылку, нажми «Проверить», выбери озвучку и жми «Скачать».

## Изменения в версиях

- **1.1.1** — аудит на баги: отмена и закрытие окна больше не оставляют ffmpeg в фоне, промах в номере серии не качает всё, resume сверяет длительность с плейлистом, `.tv` не путает сезоны и сабы, Kodik/`.tv` дают понятные ошибки вместо падений парсера. 187 тестов.
- **1.1.0** — рефакторинг на слоистую архитектуру: site-независимое ядро `core.py` + адаптеры сайтов, 153 теста на фикстурах в `tests/`, повторы HTTP при обрыве соединения, опциональный httpx-бэкенд сегментов.
- **1.0.8** — опциональный HTTP-бэкенд сегментов на `httpx` (`pip install "httpx[http2]"`, флаг `--backend httpx|urllib|auto`): качает сегменты по одному keep-alive соединению стримом на диск, без внешнего `curl.exe`. Старый путь urllib→curl сохранён и включается флагом `--backend urllib`.
- **1.0.7** — одиночный обрыв соединения (WinError 10054) повторяется автоматически: 3 попытки с паузами 0.5/1.5 с, ошибки 404 и прочие ответы сервера не повторяются.
- **1.0.6** — битые обрывки серий не пропускаются при resume: файл проверяется ffmpeg'ом, сломанный качается заново.
- **1.0.5** — субтитры как вариант скачивания (`[саб]`, `_субтитры.txt`, `--subs/--no-subs`); даб в приоритете.
- **1.0.4** — `.gitattributes`: CRLF для `.cmd`, ZIP с GitHub запускается двойным кликом.
- **1.0.3** — фикс Ctrl+V/C/X/A в GUI при русской раскладке.
- **1.0.2** — склейка v2 (бинарный кат `.ts` + ремукс), флаг `--segs 0` для диагностики.
- **1.0.1** — фикс фризов на стыках сегментов (`+genpts+igndts`, `aac_adtstoasc`).
- **1.0.0** — первый релиз форка: GUI, параллельная качка серий/сегментов, поддержка `yummyanime.tv`, установка в 1 клик.

Подробности — в [CHANGELOG.md](CHANGELOG.md).
