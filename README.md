# YummyDownloader

Качалка аниме с YummyAnime без запуска плеера: забирает HLS-поток из Kodik и складывает `.mp4` по папкам. Форк [foxycuter2-ai/YummyDownloader](https://github.com/foxycuter2-ai/YummyDownloader) с GUI на tkinter.

## Запуск (Windows)

1. `Setup_Python.cmd` — проверит Python 3.9+ и поставит зависимости.
2. Скопируй `config.example.json` в `config.json` (при желании поменяй озвучки/качество).
3. `Start_GUI.cmd` — откроется окно: вставь ссылку, нажми «Проверить», выбери озвучку и жми «Скачать».
