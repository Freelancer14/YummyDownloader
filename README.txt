YummyDownloader — качалка аниме с YummyAnime без проигрывания плеера
====================================================================

Плеер запускать не нужно — а значит, никаких спойлеров-превью.
Программа сама дёргает API сайта, берёт прямые ссылки из плеера Kodik
и качает серии в .mp4 через ffmpeg, раскладывая по папкам.

----------------------------------------------------------------
КАК ПОЛЬЗОВАТЬСЯ — ярлык на рабочем столе
----------------------------------------------------------------
1. Открой нужный тайтл на old.yummyani.me.
2. Скопируй ссылку из адресной строки (вида .../catalog/item/...).
3. Двойной клик по "Скачать аниме.cmd".
4. Вставь ссылку, Enter.
5. Программа спросит: озвучку -> качество -> серии -> всю франшизу.
   Enter на любом вопросе = значение по умолчанию.

Файлы появятся в:  YummyDownloader\downloads\<Название>\Серия NN.mp4

----------------------------------------------------------------
НАСТРОЙКИ — config.json
----------------------------------------------------------------
preferred_dubbings — список озвучек по приоритету. Берётся первая
                     доступная для тайтла. Примеры названий:
                     AniLibria, AniStar, Dream Cast, AnimeVost,
                     AniDUB, AniMaunt, Beyond:Studio.
quality            — "max" (по умолчанию, обычно 720p), либо "480"/"360".
all_seasons        — true: пройти все сезоны франшизы (по списку
                     "порядок просмотра" с сайта), каждый в свою папку.
output_dir         — куда складывать.

Замечания:
- Уже скачанные серии пропускаются (можно докачивать).
- Если у тайтла нет твоей озвучки в плеере Kodik — берётся та,
  где больше всего серий (в логе видно список доступных).
- Нужен интернет с доступом к kodikplayer.com и CDN solodcdn.com.

Требования (уже установлены): Python + пакеты certifi, imageio-ffmpeg.
ffmpeg тянуть отдельно не надо — он внутри пакета imageio-ffmpeg.
